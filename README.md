# Accepted Students

A searchable directory of students accepted into the Yale Young African Scholars (YYAS) 2026 program.

Browse Online and Residential cohorts from across Africa, or search by name to find someone quickly.

**How it helps you:** See who was accepted, connect with peers, and stay informed about the YYAS community — all in one simple place.

**Live site:** https://accepted-students.vercel.app
